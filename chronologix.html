Chronologix

Redesigning a cloud HRMS so growing organisations can unify employee data, attendance, leave, performance, and payroll into one system people actually want to open.

RoleUI/UX Designer
DeliverablesRedesigned UI
RolloutPhased — English, then Arabic
IndustryB2B
Objectives

From spreadsheets to self-service

Chronologix is a next-generation HR automation and workforce management platform built to simplify complex HR operations for growing organisations, unifying employee data, attendance, leave, performance, and payroll into one centralised system.

  • Re-design an existing HR management system into an efficient cloud HRMS / HR automation tool.
  • Address SMEs and larger businesses still tracking leave and attendance on Excel or paper.
  • Solve unstandardised onboarding/offboarding and ad-hoc performance appraisals.
  • Give HR departments visibility into analytics instead of buried admin tasks.
  • Let employees self-serve — apply for leave, view attendance, update details — without routing everything through HR.

Plan

  • Change the existing design system to feel modern, modular, and more user-friendly.
  • Redesign the dashboard for simpler, cleaner access to information.
  • Rework navigation so menu items and information access feel intuitive.
Design process

Seven phases, two language rollouts

PhaseObjective
1. Requirement AnalysisUnderstand the business, users, and competitor platforms in the same space.
2. Platform AuditAssess current designs; confirm what to retain and what to change.
3. StrategyAlign direction and priorities.
4. UX DesignFocus on learnability and simplifying the existing platform.
5. UI DesignBuild clean system visuals with theme options.
6. TestingValidate usability through stakeholder meetings.
7. HandoffCollaborate with the team and hand off phase by phase — Phase 1 (English), Phase 2 (Arabic).
