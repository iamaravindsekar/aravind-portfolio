How I work

A repeatable process,
bent to fit each brief.

01

Discover

Stakeholder interviews, competitor research, and market scoping to frame the real problem — not just the one that was pitched.

02

Define

Card sorting, personas, empathy maps, and information architecture — structuring how the system will actually work before it looks like anything.

03

Wireframe

Low-fidelity flows for every user type, reviewed against edge cases and real "what happens if" questions before visual design starts.

04

Design system

Typography, color, components, and states — built to scale across web and mobile rather than redrawn screen by screen.

05

Interface

High-fidelity screens, product illustrations, and marketing surfaces — designed module by module for easy handoff.

06

Test & handoff

Usability testing, stakeholder validation, and phase-by-phase handoff — with a design QA pass to protect the details in build.
